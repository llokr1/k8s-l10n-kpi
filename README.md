# Kubernetes 한국어 문서 기여 현황

오픈소스 컨트리뷰션 아카데미 멤버 24명이 `kubernetes/website`에서 만든 이슈, Pull Request, 머지, 다른 PR 리뷰를 수집하고 보여주는 성과 대시보드입니다.

## 제공 지표

- 전체 및 멤버별 이슈, PR, 머지, 리뷰한 PR
- 이슈 생성량과 별도로 `PR로 해결`, `진행 중`, `PR 없이 종료`, `판정 불가` 분류
- PR의 Open / Closed / Merged 상태와 GitHub 원문 링크
- 머지율, 리뷰 참여 인원, 평균 머지 소요 시간
- 달력으로 독립 설정한 활동 전·후 기간에 생성·머지된 한국어 PR, 주당 평균 PR, 이슈 생성→머지 및 PR 생성→머지 평균·중앙값 비교
- 월별 활동 추이와 멤버별 기여 분포
- 한국어 문서 PR, 변경 파일 및 라인 영향도
- 영문 최신 내용을 반영해 번역 완료된 한국어 문서 비율과 2026년 7월 11일 시작 직전·최근 수집 시점의 변화
- 날짜 범위, 활동 유형, 멤버/제목 검색 필터
- 발표용 멤버 성과 CSV 내보내기
- 최근 수집 시각 표시와 최신 게시 데이터 다시 불러오기
- PR을 중심으로 해결·관련·참조 이슈, 이슈 작성자, PR 작성자, 아카데미 리뷰어와 최종 상태를 잇는 통합 기여 현황
- 멘토 제안, 활동 시작 전 생성, 연결 이슈 없음 등 특이사항 필터와 관계 CSV
- KubeLingoAssist의 공개 릴리스·개발 커밋과 도구 도입률, 리드타임, 재작업, 번역 완료 유지율을 잇는 장기 운영 KPI 설계

GitHub ID는 모두 소문자로 정규화하여 집계합니다. 표시 이름은 `data/members.csv`에서 관리합니다.

## 로컬 실행

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run collect
npm run dev
```

인증 없이도 기본 활동을 수집할 수 있지만 API 요청 제한이 있어 시간이 걸립니다. `GH_TOKEN` 또는 `GITHUB_TOKEN`이 있으면 PR 변경 파일까지 분석하여 한국어 문서 영향 지표를 보강합니다.

```bash
GH_TOKEN=... npm run collect
```

토큰은 파일이나 저장소에 저장하지 마세요.

## GitHub Pages 배포

`.github/workflows/pages.yml`이 다음을 자동 수행합니다.

1. 매일 오전 6시 17분(KST) 또는 `main` 브랜치 푸시 시 최신 GitHub 활동 수집
2. 정적 사이트 생성
3. GitHub Pages 배포

저장소의 **Settings → Pages → Build and deployment**에서 Source를 **GitHub Actions**로 선택하면 됩니다. 수동 갱신은 Actions 탭의 `Collect metrics and deploy Pages`에서 실행할 수 있습니다.

## 집계 기준

- 대상 저장소: `kubernetes/website`
- 기간: 2026년 7월 11일 이후. 대시보드에서 이 범위 안의 시작일과 종료일을 좁혀 볼 수 있습니다.
- 이슈/PR: 작성자 GitHub ID가 멤버 목록과 일치하는 활동
- 이슈 해결 성과: 이슈 타임라인의 연결 PR이 머지되었고 PR 본문의 종료 키워드 또는 머지·종료 시점이 일치하는 경우에만 `PR로 해결`로 집계
- PR 없이 닫힌 이슈는 `PR 없이 종료`로 표시하고 해결 성과에서는 제외합니다. 연결된 머지 PR은 있으나 종료 근거가 불충분하면 `판정 불가`로 분리합니다.
- 리뷰: `reviewed-by` 검색 결과 중 본인이 작성하지 않은 PR
- 통합 기여 현황: 이슈 출처는 `멤버 생성 이슈`, `멘토 제안 이슈`, `외부 이슈`로 구분하고, `Closes`, `Fixes`, `Resolves` 연결은 `해결할 이슈`, 그 밖의 관련·참조 링크는 `기타`로 간략히 표시
- 출처 유형은 해결할 이슈를 우선해 대표 이슈 한 건을 선정한 뒤 PR당 하나만 표시합니다. 대표 이슈 작성자가 PR 작성자 또는 다른 아카데미 멤버이면 `멤버 생성 이슈`로 분류합니다.
- 멘토가 작성하고 멤버 PR로 해결한 이슈는 `멘토 제안 이슈`로 분류하며 멤버의 이슈 생성 건수에는 포함하지 않습니다.
- 한국어 PR: 인증 수집 시 변경 파일이 `content/ko/` 또는 `i18n/ko/`에 포함된 PR. 미인증 수집 시 제목 `[ko]`와 한국어 로컬라이제이션 라벨로 판별
- 번역 완료율: [Kubernetes i18n Tracker](https://kfess.github.io/kubernetes-i18n-tracker/?page=1&lang=ko)의 `up_to_date` 판정을 사용. 한국어 문서가 존재하고 한국어 최신 커밋이 영문 최신 커밋보다 늦으며 Markdown 제목 구조가 일치하는 문서만 완료로 집계
- 활동 전후 비교: 기본값은 최근 수집일까지의 활동 후 기간과 바로 앞의 같은 길이 기간이며, 성과 개요의 달력에서 두 기간의 시작일과 종료일을 각각 변경할 수 있습니다. `[ko]` 제목 규칙을 사용한 `kubernetes/website` PR 전체를 대상으로 생성 PR은 생성일, 머지 건수·소요일은 머지일 기준으로 집계합니다.
- 달력 비교는 정기 수집본에 저장된 PR별 생성일·머지일·종료 이슈 생성일을 브라우저에서 다시 계산하므로 GitHub 토큰이나 추가 API 호출이 필요하지 않습니다. 기간 길이가 다르면 원시 건수보다 주당 평균 PR을 우선 비교합니다.
- 이슈 생성→머지 소요일은 PR 본문에 종료 키워드로 연결된 이슈가 확인된 표본만 포함합니다. 프로젝트 전체의 전후 변화이므로 아카데미 활동만의 단독 인과로 해석하지 않습니다.
- KubeLingoAssist: [공개 저장소](https://github.com/k8s-kr/kubelingoassist)의 릴리스·커밋을 수집합니다. 사용 횟수는 현재 텔레메트리가 없으므로 실적으로 표시하지 않고, PR 템플릿에 도구 사용 여부를 남긴 뒤 도입률·리드타임·재작업·30/60/90일 번역 완료 유지율을 추적하도록 설계했습니다.

GitHub 웹 화면에 기록되지 않은 Slack·회의·구두 리뷰는 포함되지 않습니다.
